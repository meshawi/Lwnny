PawnIO modules used by Lwnny
============================

SmbusPIIX4.bin - AMD FCH (PIIX4-compatible) SMBus access module.
Source: https://github.com/namazso/PawnIO.Modules (release 0.2.11)
License: LGPL-2.1 (see COPYING). The module is loaded unmodified into the
PawnIO driver (https://pawnio.eu), which must be installed separately.
